# sonora · 本地音频批量转换器（移动端优化）

此提交在之前版本的基础上，针对手机/触控设备做了以下改进：

- 添加“相机拍摄”功能：在移动设备上可以直接调用系统相机拍摄视频/录音并加入队列（使用 HTML input capture）。
- 为视频/音频队列项生成缩略图与时长：提高队列可读性，便于在移动端快速识别文件。
- 增大触控目标与按钮（更大的间距、内边距与字体），提高在小屏幕上的可点击性。
- 队列项显示更明显的缩略图区域，便于快速浏览。
- 自动回收 objectURL，减少内存泄漏（移除项/清空队列/完成后回收下载 URL）。

注意事项：
- 相机功能依赖设备与浏览器对 input.capture 的支持，不同设备行为可能稍有差异。
- 缩略图生成会尝试截取视频首帧，部分视频格式或编码可能因安全/解码限制而失败（会退回到无缩略图显示）。
