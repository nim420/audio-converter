# sonora · 本地音频批量转换器

此版本新增批量队列、拖拽批量上传、输出预设与下载历史（保存在 localStorage）。

使用说明：

- 在页面中拖入或选择多个文件，会进入“转换队列”。
- 通过“预设”选择常见输出配置（会应用到新加入的队列项）。
- 点击“全部转换”或单个项的“转换”按钮开始处理。为节省内存和避免同时运行多个 ffmpeg 实例，队列会按序逐个处理。
- 转换完成后会自动将导出的文件添加到“下载历史”，你可以随时重新下载。

实现要点：

- MIDI：采用 @tonejs/midi 解析，并在 OfflineAudioContext 中用简单正弦合成器合成音频。
- MP3/FLAC：采用 ffmpeg.wasm 在浏览器端进行编码。首次转换需要下载 WASM 资源。
- WAV：作为中间格式生成，适配所有后续编码流程。

限制与建议：

- ffmpeg.wasm 的资源较大，首次使用 MP3/FLAC 转换时请耐心等待下载完成。
- 浏览器对特定视频/音频编码的解码能力有限，某些容器/编码可能无法解码。
- 下载历史仅保存在本地浏览器的 localStorage。如需更持久或跨设备同步，可集成外部存储服务（会改变隐私承诺）。
